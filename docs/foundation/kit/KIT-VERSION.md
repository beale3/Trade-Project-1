> **When you improve the kit** (you will, every founding): add a `FOUNDING-LESSONS.md` entry, fold the fix into the affected file(s) **and the relevant `roles/` lessons block**, bump the version here with a new row naming that lesson, then push to the canonical mirror (`INHERITANCE-AND-MIRROR.md`). **The self-improving property dies the moment a founding skips the lesson step** — so a founding that "found nothing" still writes the "nothing to add" line.
